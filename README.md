# 커밋 크래프트: 시간의 나무 (Commit Craft)

문서끼리 내용이 다르면 Git 동작은 **시뮬레이터 명세**, 스테이지·별점·필수 경로는 **스테이지 명세**, 온라인 개인/팀 판정은 **협업 설계**, 릴리스 범위·일정은 **구현 계획서**를 기준으로 합니다. 게임 기획서는 전체 방향과 장기 확장을 설명합니다.

## 현재 기획 범위

- **첫 시범 MVP**: 4차시 필수 경로 **20개**, 게임 140분 + 운영·평가 60분 = 총 200분 목표. 아직 실측 전 예산입니다.
- **확장 MVP**: 프롤로그 + 챕터 1~5 전체 **34개**, 순수 게임 약 220분 추정, 6~8차시 편성. PR·리뷰·Fork는 2차 범위입니다.
- 첫 시범은 P0에서 **배포 1종·서버 1종**을 선정하고 2인 협업 + NPC 대체를 검증합니다. 기본 후보는 exe + 교실 서버이며 학교 검증 전 확정하지 않습니다.
- 별점은 조회·실패 명령·힌트 사용으로 낮아지지 않습니다. 1-4에서 add 시점 스냅샷을, 협업판에서 각 학생의 거절·복구 및 충돌 해결을 확인합니다.
- 개발 기간은 실제 주당 작업 시간을 기록한 뒤 재산정합니다. 기존 24주는 전체 범위·1인 풀타임의 초기 추정입니다.

## 게임 프로젝트
[`game/`](game/) — Godot 4.7.1 프로젝트. 지금은 **P0 기술 스파이크**(한글 입력·터미널·커밋 그래프·교실 네트워크 시험 화면)와 첫 핵심 로직(건물 파일 형식, 한/영 전환 감지), 헤드리스 테스트가 들어 있습니다. Windows에서 여는 법은 [`game/README.md`](game/README.md).

별도 **3D 쿼터뷰 마을 시안**은 로컬 모델 또는 대체 도형으로 실행할 수 있습니다. Git 시뮬레이터·스테이지 진행·진도 저장은 아직 미구현이며, 학교 PC 검증도 남아 있습니다.
