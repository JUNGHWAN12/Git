# 개발 점검 후속 수정 계획

> 실행: 현재 세션에서 직접 수정한다. 기존 미커밋 문서·마을 시안을 보존하며 커밋·푸시하지 않는다.

**목표:** 점검에서 확인한 마을 렌더 문서 불일치와 로컬 에셋 의존을 보완한다.

**기준:** `docs/superpowers/specs/2026-11-03-village-view-design.md`. 정식 마을 시스템 전체가 아닌 P0 시안 보완이다.

**구현 선택:** 기존 `village_spike.gd`에 모델 로딩·대체 도형 생성을 묶고, 모델이 없으면 기본 도형을 생성한다. `--no-pack`으로 같은 경로를 재현한다. 별도 정식 레지스트리·레이아웃 계층 도입은 후속으로 남긴다.

## 작업

- [x] 기존 15개 테스트 기준선 재확인.
- [x] 11개 종류의 에셋 없는 생성, 층수 차이, 구역 내 건물 수·색상 유지 테스트를 먼저 작성하고 실패 확인.
- [x] 모델 존재 여부 확인 후 로딩, 대체 도형, `--no-pack` 옵션 구현 및 테스트 통과 확인.
- [x] 구현 계획·Godot 아키텍처를 마을 한정 3D 쿼터뷰 기준으로 정리하고 실제 구현/계획을 구분.
- [x] 실행 안내와 P0 현장 기록 양식 작성. 학교 검증 결과는 미검증으로 유지.
- [x] 전체 테스트, 기본·마을 장면 시작, 에셋 없는 장면 시작, 공백 오류 검사 및 최종 리뷰.

## 결과

회귀 테스트 4개를 구현 전 실패 확인 후 수정했고, 전체 19개가 통과했다. 세 장면 시작 점검은 모두 오류 없이 종료했다. 모델/대체 도형 스크린샷을 확인했고 별도 읽기 전용 코드 리뷰에서 수정이 필요한 결함은 보고되지 않았다. 실제 학교 PC·IME·성능·교실망은 미검증이며, 기존 고정 슬롯의 겹침·정식 마을 기능은 이번 범위 밖으로 유지했다. 기존 사용자 작업은 보존했으며 커밋·푸시는 하지 않았다.

## 검증 명령

Godot 4.7.2 콘솔 실행 파일로 다음 인자를 실행한다.

```text
--headless --path game --script res://tests/run_tests.gd
--headless --path game --quit-after 60
--headless --path game res://scenes/spike/village_spike.tscn --quit-after 60
--headless --path game res://scenes/spike/village_spike.tscn --quit-after 60 -- --no-pack
```

`RESULT: passed=N failed=0`, 각 장면 오류 없음, `git diff --check` 통과를 확인한다. 화면 가독성·IME·성능·학교망 검증은 별개다.
