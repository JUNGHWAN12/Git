# P0 검증 기록

> 2026-11-03 기준. 로컬 자동 검증은 P0의 일부이며 학교 현장 통과를 뜻하지 않는다.

## 로컬 검증

| 항목 | 결과 | 범위·제한 |
|---|---|---|
| 엔진 | `4.7.2.stable.official.ed1daf0bf` | Windows 표준판 콘솔 실행 파일 |
| 헤드리스 테스트 | 19개 통과, 실패 0 | 한/영 감지 5, 건물 파일 6, 통신 3, 마을 시안 4, 컴파일 1 |
| 에셋 누락 회귀 | 11개 종류의 도형 생성, 집 층수 차이, 구역 건물 수·틴트 확인 | 없는 모델 경로 자동 대체와 `use_pack_models=false` 모두 검사 |
| 장면 시작 | 기본 P0·모델 마을·`--no-pack` 마을 모두 오류 없이 종료 | 각 60프레임 헤드리스 실행, 종료 코드 0 |
| 마을 화면 | 모델 사용·대체 도형 두 경로의 스크린샷 확인 | 로컬 RTX 3090·Compatibility. 색상·층수 차이와 4개 구역 확인. 라벨과 건물 겹침은 기존 시안 한계로 남음 |

실행: 저장소 루트에서 `godot --headless --path game --script res://tests/run_tests.gd`. Windows는 실제 Godot 콘솔 exe 경로를 사용한다. 로그의 `RESULT: passed=19 failed=0`과 종료 코드 0을 확인했다.

화면 시작 점검은 `--headless --path game --quit-after 60`으로 기본 장면, `res://scenes/spike/village_spike.tscn`을 지정해 마을 시안을 검사한다. 에셋 없는 경로는 마지막에 `-- --no-pack`을 추가한다. 헤드리스 실행은 화면 품질·IME·GPU 성능을 검증하지 않는다.
