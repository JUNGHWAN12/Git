# 🎮 엔진별 비교: Unity · Unreal · Godot · Web
### 「커밋 크래프트」 구현 엔진 선정 보고서

> 이 게임의 성격: **UI 비중이 큰 퍼즐 게임**(터미널, 커밋 그래프, 충돌 편집기) + 가벼운 2.5D 마을 + 교실 협업 + **학교 컴퓨터/크롬북 배포**.
> 따라서 "가장 좋은 엔진"이 아니라 **"이 게임과 학교 환경에 가장 맞는 엔진"** 을 기준으로 비교한다.
> 라이선스·웹 내보내기 지원 범위는 버전마다 바뀌므로 개발 착수 시점에 공식 문서로 재확인한다.

## 2. 가중치 점수표 (학교 보급형 기준)

이 게임은 학교에서 돌아가는 것이 가장 중요하므로 배포·저사양·UI에 가중치를 크게 두었다. (각 항목 1~5점 × 가중치)

| 평가 항목 | 가중치 | Unity | Unreal | Godot | Web |
|---|---:|:---:|:---:|:---:|:---:|
| 학교 배포 용이성 (설치 불필요·보안 정책) | 25 | 4 | 1 | 4 | 5 |
| 저사양 PC·크롬북 동작 | 15 | 3 | 1 | 5 | 5 |
| UI 제작 생산성 (터미널·그래프·편집기) | 15 | 3 | 2 | 4 | 5 |
| 개발 비용 | 10 | 4 | 2 | 5 | 4 |
| 인력 수급 | 10 | 5 | 3 | 2 | 5 |
| 멀티플레이 구현 | 10 | 4 | 5 | 3 | 4 |
| 3D·시각 연출 | 5 | 4 | 5 | 3 | 2 |
| 실제 Git 연동 가능성 | 5 | 3 | 3 | 2 | 5 |
| 유지보수·업데이트 배포 | 5 | 3 | 2 | 4 | 5 |
| **합계 (100점 환산)** | **100** | **74** | **44** | **76** | **93** |

**가중치를 바꾸면 순위도 바뀐다.**
- 3D 연출·VR·전시 품질을 가장 중요하게 보면 → Unity / Unreal이 올라온다.
- 앱스토어 출시(모바일/태블릿 네이티브)가 중요하면 → Unity가 올라온다.
- 예산이 0원이고 개발자가 1~3명이면 → Godot이 올라온다.

## 4. 엔진별 장단점 카드

### 🟦 Unity
- **장점**: PC·웹·태블릿·모바일을 한 프로젝트로 / 인력 가장 많음 / 2.5D 마을·연출 쉬움 / 에셋 풍부
- **단점**: WebGL 한글 입력 문제 / UI 대량 제작이 웹보다 느림 / 라이선스 정책 변경 이력
- **이럴 때 선택**: 앱스토어 출시, 3D 연출 중시, 팀이 Unity 숙련, 상용 에듀테크 제품

### 🟥 Unreal Engine 5
- **장점**: 최고 수준 그래픽 / VR 체험 / 내장 멀티플레이 강력 / Blueprint로 비개발자도 연출 가능
- **단점**: 웹 배포 사실상 불가 / 학교 PC에서 무거움 / UI 위주 게임에는 과함 / 비용·기간 가장 큼
- **이럴 때 선택**: 과학관·박람회 전시, VR 체험관, 홍보 영상용 **별도 쇼케이스판**

### 🟩 Godot 4
- **장점**: 완전 무료(MIT) / 매우 가벼움 / UI 노드 시스템 우수 / 씬 파일이 텍스트라 Git 친화적 / 배우기 쉬움
- **단점**: 국내 인력 적음 / 웹 내보내기 시 C# 제약·한글 입력 확인 필요 / 에셋·레퍼런스 적음
- **이럴 때 선택**: 교사·학생 동아리 개발, 예산 0원, 오픈소스로 공개해 수업 재료로 활용

### 🟨 Web (TypeScript + React/Phaser 등)
- **장점**: 설치 없이 어디서나 / 크롬북·태블릿 OK / 터미널·그래프·편집기·한글 입력 모두 쉬움 / 브라우저에서 진짜 Git 가능 / 교사 대시보드까지 한 기술로 / 업데이트 즉시 반영
- **단점**: 화려한 3D 연출은 비용 큼 / 게임 엔진 편의 기능(애니메이션 툴 등) 부족 / 네이티브 앱 느낌 약함
- **이럴 때 선택**: **학교 보급이 최우선일 때 (이 게임의 기본 상황)**

## 5. 같은 기능, 엔진별 코드 느낌

"커밋을 만들고 그래프에 반영" 하는 부분을 엔진별로 비교하면 다음과 같다. (Git 코어는 공통 로직, 아래는 화면 연결 부분)

**Unity (C#)**
```csharp
public class CommitButton : MonoBehaviour {
    [SerializeField] GraphView graph;
    public void OnClick() {
        var commit = GitSim.Repo.Commit(messageInput.text);   // 공통 코어 호출
        graph.AddNode(commit.Id, commit.Parents);              // 나무에 열매 추가
        Terminal.Echo($"git commit -m \"{commit.Message}\"");  // 하이브리드 모드
    }
}
```

**Unreal (C++ — Blueprint에서도 호출 가능)**
```cpp
UFUNCTION(BlueprintCallable, Category="GitSim")
FCommitInfo UGitSimSubsystem::MakeCommit(const FString& Message) {
    FCommitInfo Info = Core->Commit(TCHAR_TO_UTF8(*Message)); // 공통 코어 호출
    OnCommitCreated.Broadcast(Info);                          // 위젯/연출이 구독
    return Info;
}
```

**Godot (GDScript)**
```gdscript
func _on_commit_pressed() -> void:
    var commit := GitSim.repo.commit($MessageInput.text)  # 공통 코어 호출
    $Graph.add_node(commit.id, commit.parents)
    $Terminal.echo('git commit -m "%s"' % commit.message)
```

**Web (TypeScript + React)**
```tsx
function CommitButton({ message }: { message: string }) {
  const repo = useRepo();
  return (
    <button onClick={() => {
      const commit = repo.commit(message);        // 공통 코어 호출
      terminal.echo(`git commit -m "${message}"`); // 그래프는 상태 변경으로 자동 갱신
    }}>크리스탈 봉인</button>
  );
}
```

> 공통점: 어느 엔진이든 **Git 코어는 엔진 밖에 두고 화면만 엔진이 담당**한다. 그래서 엔진을 바꾸거나 두 개를 같이 써도 규칙·스테이지 데이터는 그대로 재사용된다.

## 6. 상황별 최종 추천

| 상황 | 1순위 | 2순위 | 피할 것 |
|---|---|---|---|
| 일반 학교 보급 (크롬북·저사양 포함) | **Web** | Godot (Web 내보내기) | Unreal |
| 교사 1인 / 학생 동아리 개발 | **Godot** | Web | Unreal |
| 에듀테크 기업 상용 제품 (앱스토어 포함) | **Unity** | Web + 네이티브 래핑 | — |
| 3D 마을 연출을 강하게 | **Unity** | Unreal | Web |
| 과학관·박람회·VR 체험 | **Unreal** | Unity | Web |
| 기기·네트워크 없음 | 언플러그드 카드 게임 | — | — |

### 추천 조합 (본 프로젝트)
1. **기본안: Web 단독** — 게임 + 교사 대시보드 + 실제 Git(isomorphic-git)까지 한 기술로. 학교 배포에 가장 유리.
2. **3D 강화안: Unity(게임) + Web(교사 대시보드)** — 연출 품질을 올리되, WebGL 한글 입력 대책을 초기에 검증.
3. **저예산안: Godot + GitHub 공개** — 학생이 게임 소스에 직접 PR하는 수업까지 연결.
4. **쇼케이스: 위 기본안 + Unreal 전시판** — 챕터 1·3·4만 고품질 VR로 별도 제작.

- [ ] 학교에서 프로그램 설치가 가능한지, 어떤 사이트가 차단되는지
- [ ] 개발팀이 가장 익숙한 엔진/언어
- [ ] 앱스토어 출시가 필요한지
- [ ] 3D 연출이 학습 효과에 꼭 필요한지 (대부분 2.5D로 충분)
- [ ] **선택 엔진에서 웹 빌드 한글 입력 테스트 (1주차)**
- [ ] 엔진 라이선스·웹 내보내기 지원 범위를 공식 문서로 재확인
- [ ] 서버 운영 주체와 비용 (교사 PC / 교육청 / 기업 클라우드)
